# 英雄联盟皮肤信息查询 LOL Skin Information Searching

一个适用于 Windows 的《英雄联盟》国服皮肤信息查询工具。

输入皮肤名或英雄名，即可查询皮肤资料；支持皮肤 ID、英雄称号、英文英雄名与多个关键词组合搜索。皮肤详情以表格呈现。

**当前版本：v1.0 · Windows 10 / 11 x64 · 内置 1970 条皮肤记录**

## 下载与使用

下载仓库中的 [LOL-Skin-Information-Searching_v1.0.exe](./LOL-Skin-Information-Searching_v1.0.exe)，双击运行，无需安装。

查询功能可离线使用，无需启动英雄联盟客户端。

| 操作 | 示例或说明 |
| --- | --- |
| 按皮肤名查询 | `铁哥们儿` |
| 按英雄名查询 | `奥拉夫`、`拉莫斯` |
| 按英雄称号查询 | `黑暗之女` |
| 按英文英雄名查询 | `Annie` |
| 按皮肤 ID 查询 | `33035` |
| 组合关键词 | `李青 神龙`，关键词之间用空格分隔 |
| 定位搜索框 | `Ctrl + F` |
| 清空搜索 | `Esc` 或点击“清空” |
| 复制详情 | 点击“复制表格”，可粘贴至 Excel 等工具 |

## 查询内容

| 字段 | 内容 |
| --- | --- |
| 皮肤 ID | 用于区分皮肤的客户端内部标识 |
| 皮肤中文名 | 国服中文名称 |
| 英雄 | 所属英雄的中文名 |
| 品质 | 以 T0—T5 形式呈现的参考分级 |
| 国服售价 | 原始售价；根据情况使用点券、神话精粹、礼包或通行证价格，无独立售价的皮肤单独标明 |
| 发行日期 | 已收录的国服或全球首发日期 |
| 获取方式 | 首次发售渠道；后续常驻直售的记录按直售整理 |
| 是否限定 | 已收录的限定状态；证据不足的记录保留“待核实” |
| 备注 | 目前是否直售、是否可购买 |

## 数据范围与口径

- v1.0 固定收录 1970 个皮肤 ID，不包含炫彩和臻彩，保留至臻皮肤。该数量是当前内置数据集的规模。
- 售价以国服原始非促销价格为目标口径。礼包专属、通行证、神话兑换与活动赠送等情况分别标明；礼包或通行证价格不等同于皮肤单独直售价。
- T级是参考分类，不是国服客户端统一的官方等级。名人堂礼包中的阿狸、卡莎、小炮，殿堂传奇与联盟不朽共六款归为 T0；其余按收录的制作特征整理。
- 目前是否可购买与历史原价分别记录。商城、活动与奖池可能变化，以游戏内实际展示为准。
- 部分历史价格、首发渠道与当前购买状态仍有待核实项。数据已填入数值不代表全部记录都已获得独立首售公告证明。

逐条依据、来源链接与待核实项保存在 [`source/data/skins.json`](./source/data/skins.json) 中，便于后续校订。

## 更新检测

程序内置本项目的 GitHub 仓库地址，每次启动会在后台检查一次正式 Release。发现高于本机版本的新版本时，提示用户前往 GitHub 下载。

- 无新版本时不弹窗。
- 自动检查遇到断网、超时或请求限制时，不影响离线查询。
- 点击右上角“更新设置”，可查看或修改仓库地址，并手动检查。
- 仅提醒并打开版本页面，不自动下载、运行或覆盖本地程序。

更新检测读取 GitHub Releases，正式版本标签使用 `v1.0`、`v1.0.1`、`v1.1` 等数字形式。仅上传代码或创建 Git 标签，不会触发新版本提醒；仓库尚无正式 Release 时也不会提示更新。

## 从源码构建

依赖：**Python 3** 与 **Zig 0.14.1**。Python 无需安装第三方包。

在 `source` 目录执行：

```sh
python build.py
```

Windows 下也可双击 `source/build-windows.cmd`。构建结果为源码目录上一级的 `LOL-Skin-Information-Searching_v1.0.exe`。

Linux 交叉编译可指定 Zig 路径：

```sh
ZIG=/path/to/zig python3 build.py
```

| 源码文件 | 用途 |
| --- | --- |
| `source/main.c`、`source/theme.h` | 窗口界面、查询与表格展示 |
| `source/core.h` | 关键词匹配 |
| `source/updater.h`、`source/update_core.h` | GitHub 更新检测与版本比较 |
| `source/update_config.h` | 版本号与默认仓库地址 |
| `source/data/skins.json` | 皮肤数据、核查依据与来源 |
| `source/generate_data.py` | 生成程序内置数据 |
| `source/build.py` | Windows x64 构建脚本 |
| `source/tests/` | 查询与更新逻辑测试 |

构建时会自动从 JSON 生成 `skins_data.h`。修改皮肤记录后，重新运行构建脚本即可。
